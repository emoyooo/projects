# Проект 15: Мультиагентные дебаты с AutoGen

Мультиагентная диалоговая система для структурированных дебатов на базе Microsoft AutoGen.

## Участники

| Агент | Роль | Температура |
|---|---|---|
| 🎙️ **Модератор** | Управляет ходом дискуссии, подводит итоги | 0.2 |
| 🚀 **Оптимист** (Алексей Новиков) | Технооптимист, апеллирует к данным и прецедентам | 0.7 |
| 🔍 **Скептик** (Марина Соколова) | Исследователь рисков, задаёт острые вопросы | 0.7 |
| 📊 **Аналитик** (Дмитрий Волков) | Финансист, оценивает рыночные тренды и ROI | 0.7 |

## Структура проекта

```
project-15-multiagent-debate/
├── agents/
│   ├── __init__.py
│   ├── optimist.py      # Агент-технооптимист
│   ├── skeptic.py       # Агент-скептик
│   ├── analyst.py       # Финансовый аналитик
│   └── moderator.py     # Агент-модератор
├── config/
│   ├── __init__.py
│   └── llm_config.py    # Конфигурация LLM
├── output/
│   └── debate_log.md    # Последний лог дебатов
├── main.py              # Точка входа
├── requirements.txt
├── .env                 # API ключи (не коммитить!)
└── README.md
```

## Установка

```bash
pip install -r requirements.txt
```

Создайте `.env` файл:
```
OPENAI_API_KEY=sk-...
```

## Запуск

```bash
# Дебаты по умолчанию (ИИ vs программисты)
python main.py

# Своя тема
python main.py --topic "Стоит ли компании перейти на ИИ-контент?"

# Больше раундов
python main.py --rounds 20

# Без модератора (round-robin)
python main.py --no-moderator
```

## Архитектура

```
UserProxy (инициатор)
    │
    ▼
GroupChatManager
    │
    ├── custom_speaker_selection()
    │       Модератор → Оптимист → Скептик → Аналитик
    │       Модератор вступает каждые 3 реплики дебатёров
    │
    ├── 🎙️ Модератор    (MODERATOR_LLM_CONFIG, temp=0.2)
    ├── 🚀 Оптимист     (BASE_LLM_CONFIG, temp=0.7)
    ├── 🔍 Скептик      (BASE_LLM_CONFIG, temp=0.7)
    └── 📊 Аналитик     (BASE_LLM_CONFIG, temp=0.7)
```

## Вывод в файл

Каждый запуск создаёт два файла:
- `output/debate_log.md` — последний лог (перезаписывается)
- `output/debate_log_YYYYMMDD_HHMMSS.md` — с временной меткой

## Наблюдения

- Разная температура (0.2 vs 0.7) даёт заметную разницу в стиле: модератор — сухой и точный, дебатёры — живые
- `custom_speaker_selection` критически важна: без неё модератор либо монополизирует дискуссию, либо теряется
- Системные промпты с ограничением длины реплики («не более 4–5 предложений») делают диалог динамичнее
- Указание конкретных данных в промпте (GitHub Copilot 40%, MIT studies) заставляет агентов аргументировать цифрами
